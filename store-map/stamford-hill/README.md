# Photos for the Stamford Hill store map

Drop photos in this folder (jpg/png/heic, any size). Nothing reads them automatically:
Claude looks at them when asked to fill in `../stamford-hill.json`.

## What to take

1. **The aisle-end signs.** Stand at the end of each aisle facing the sign, so every word is readable.
   One photo per aisle. Name: `aisle-07-sign.jpg` (two digits).
2. **Mid-aisle signs** if an aisle's categories change halfway (e.g. tins then pasta).
   Name: `aisle-07-mid.jpg`.
3. **Non-aisle areas**, one wide photo of each with its overhead sign:
   `zone-fruit-veg.jpg`, `zone-bakery.jpg`, `zone-chillers-dairy.jpg`, `zone-meat-fish.jpg`,
   `zone-frozen.jpg`, `zone-tills.jpg`, `zone-deli.jpg`.
4. **Optional layout sketch**, a photo of a hand drawing or the store's own map, with the entrance marked:
   `layout.jpg`.
5. **Walk order:** take the photos in the order you walk, or tell Claude the order. The order decides
   `walkOrder` (1 = first zone you reach, rising to the tills).
